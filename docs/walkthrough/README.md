# AudioFetch walkthrough

https://github.com/user-attachments/assets/73c4f846-7593-4ab1-b06e-7fd8bf3b1400

**Video:** [AudioFetch-walkthrough.mp4](AudioFetch-walkthrough.mp4) (8:54, 1366×768). A guided tour with captions, recorded in the real app while downloading three songs:

- [Silver Bullet - NOBODY ELSE](https://www.youtube.com/watch?v=5R3UPTNDBoM)
- [Silver Bullet, Jess Cullity - Watching You](https://www.youtube.com/watch?v=2RbKo0GmiCo)
- [DJ PUMA - REWIND](https://www.youtube.com/watch?v=aVw71vt-U4s)

The first download plays in real time to show the live progress. The two queued downloads are sped up 4×, marked "⏩ 4× speed" on screen.

Two parts use examples, and are labelled as such in the video:

- **Chapters:** none of these three videos has chapters, so an example chapter list shows how splitting works.
- **Lyrics:** LRCLIB has no lyrics for these songs. The video first shows the real "No lyrics found" result, then example lines to show timed lyrics.
